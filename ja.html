Flick Land プライバシーポリシー

施行日：2026-10-17（以前の版：2026-10-16、2026-09-30）

このページは韓国語のポリシーの翻訳です。内容が異なる場合は韓国語のポリシーが優先されます。

itkong（以下「開発者」）は、モバイルゲーム Flick Land（パッケージ com.ponykit.flickland、以下「アプリ」）を提供しています。アプリは開発者が運営する Ponykit Games ゲームサーバー（以下「サービス」）に接続します。サービスが取り扱う個人情報は Ponykit Games プライバシーポリシー（韓国語）に従い、このページでは Flick Land のみに関する内容をお知らせします。

1. 概要

  • 初めて起動すると、名前や連絡先なしでランダムなアカウント（ゲストアカウント）がサービスに作られます。希望すれば Google アカウントを連携できます。
  • ニックネームとキャラクター、ジェム・石・スキン、試合記録、ミッション、フレンド、ランキングはサービスに保存され、サービスが判定します。
  • アプリは Google AdMob の広告を表示します。リワード広告は利用者がボタンを押したときだけ表示され、ショップ画面の下にはバナー広告が1つ表示されます。広告が表示されるとき、Google が広告 ID などの端末情報を直接収集します（5章）。
  • アプリには広告以外の分析（アナリティクス）・エラー報告ツールはありません。開発者は個人情報を販売しません。
  • アプリ設定のアカウント削除メニュー（このメニューが入ったバージョンから）またはメールで、アカウントとデータを削除できます（4章）。

2. サービスに保存される情報

項目と目的、保存期間、処理の委託は Ponykit Games プライバシーポリシーの2〜6章にあります。Flick Land では次の情報が含まれます。

  • アカウント情報：ランダムなアカウント ID、ログインセッション、Google アカウントを連携した場合は Google アカウントの識別子
  • プロフィール：ニックネーム、選んだキャラクター
  • ゲームデータ：ジェムの残高と増減の履歴、所持している石・スキン、試合結果と最後の試合の状態、ミッションの進行と報酬の受け取り履歴、広告報酬の履歴（広告視聴チケット、視聴時刻、支給結果、結果画面の報酬は該当する試合 ID）、ランキング
  • フレンド：フレンドコード、フレンド申請とフレンド関係
  • オンライン対戦：ルームコードと試合中にやり取りする操作情報。相手の利用者にはニックネーム、キャラクター、石のデザインが表示されます。

3. 端末内だけに保存される情報

設定（サウンド、振動、操作感度など）、チュートリアルの進行状況、最近の試合記録のコピー、ログイン状態を保つためのトークンは利用者の端末に保存されます。アプリを削除したりアプリのデータを消去したりすると端末内の情報は削除されますが、サービスに保存されたアカウントは4章の方法で削除する必要があります。

4. アカウントの削除

  1. アプリ設定画面の「アカウント削除」メニュー（このメニューが入ったバージョンから）：確認後すぐに削除されます。
  2. メール（ponykit@gmail.com）：アプリを使えない場合やメニューのないバージョンの場合は、件名に「アカウント削除」、本文に「Flick Land」とフレンド画面のフレンドコードを書いてお送りください。確認後30日以内に削除し、結果をお知らせします。

削除される情報と残る可能性のある情報は、Ponykit Games プライバシーポリシーのアカウント削除の申請にあります。削除したアカウントは元に戻せず、ジェム・石・スキンも一緒に失われます。

5. 広告

  • ショップの広告ボタンや試合結果画面の「広告を見てジェム」ボタンを押したときだけリワード広告が表示され、最後まで見るとサービスがジェムを支給します。1日に見られる回数はサービスが決めます。
  • ショップ画面が開いている間、画面の下にバナー広告が1つ表示されます。ゲーム中や画面の切り替え時に表示される全画面広告はありません。
  • 広告は Google LLC の Google Mobile Ads SDK（AdMob）が配信します。Google は広告を選んで表示し、成果を測定し、不正クリックを防ぐために、端末から広告 ID などの端末識別子、IP アドレス（おおよその位置）、広告の表示・クリックなどのアプリ内のやり取り、診断情報を直接収集します。開発者は広告 ID を受け取ったり保存したりしません。
  • 法律で求められる地域では最初の広告の前に Google の同意画面が表示され、アプリ設定の「広告の選択」からいつでも変更できます。端末の設定（Google › 広告）で広告 ID をリセットまたは削除することもできます。
  • 詳しくは Ponykit Games プライバシーポリシー7章と Google による情報の取り扱いをご確認ください。

6. アプリの権限

  • インターネット・ネットワーク状態：サービスへの接続、オンライン対戦、広告のための権限です。
  • 振動：ゲームの効果のための権限です。
  • 広告 ID（com.google.android.gms.permission.AD_ID）：Google の広告 SDK が広告 ID を読み取るための権限です。

7. 子どもの個人情報

サービスは13歳以上の利用者を対象としており、13歳未満の子どもの個人情報を知りながら収集することはありません。広告は13歳以上に適したレーティング（PG）以下に制限しています。

8. 変更

このポリシーが変わる場合は、施行日とともにこのページに掲載します。収集する項目が新しく増える変更は、その機能を含むアップデートの前に掲載します。
